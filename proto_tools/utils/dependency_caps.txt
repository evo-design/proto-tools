# Caps on GPU-, driver- and compiler-coupled packages at the newest versions we have tested.
#
# Every env build passes this file to `uv pip` and `pip` as a constraints file (UV_CONSTRAINT /
# PIP_CONSTRAINT), so it also caps indirect dependencies. See proto_tools/utils/dependency_caps.py
# and notes/tool-environments.md.
#
# Rules:
# - Caps are set and raised by hand only, in a PR with GPU test evidence and a second reviewer.
#   Nothing generates or raises them automatically.
# - Each cap is the next minor version above the newest tested one (3.8.x -> <3.9). JAX numbers
#   every release as a patch, so its caps sit just above the tested release (0.12.0.1 -> <0.12.1).
# - Each line ends with `# tested <version> | <date> | <hardware> | <evidence>`, or, for a CUDA 13
#   build we have no hardware to test, `# follows <cu12 package>` with the same bound.
# - Cap only packages tied to the GPU, driver or compiler that release often.
