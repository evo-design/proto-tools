# pandas 3 backs string columns with PyArrow by default, so ``DataFrame[col].values`` returns an
# ArrowExtensionArray; ``gene_mask.finalize_variant`` indexes that result with ``[None]``
# (numpy newaxis), which only a numpy-backed array accepts. Without this bound a fresh env resolves
# pandas 3 and breaks alphagenome-score-variants and alphagenome-score-ism-variants-batch.
