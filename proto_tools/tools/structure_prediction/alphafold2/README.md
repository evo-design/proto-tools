## Overview

AlphaFold2 (AF2) is Google DeepMind's second-generation AlphaFold, widely regarded as the first method to predict protein structures from sequence at near-experimental accuracy. This toolkit runs AF2 through [ColabDesign](https://github.com/sokrypton/ColabDesign), the open-source JAX implementation from [Sergey Ovchinnikov's group](https://www.solab.org/), to predict 3D structures of proteins and complexes and to score and differentiate binders against a fixed target.

## Background

AlphaFold2 ([Jumper et al., 2021](https://doi.org/10.1038/s41586-021-03819-2)) predicts a protein's 3D structure from its amino-acid sequence, and was introduced at the CASP14 structure-prediction assessment in 2020. AF2 takes a multiple-sequence alignment (MSA) as a primary input. The MSA carries an evolutionary signal: residues that lie close together in the folded structure tend to mutate in a correlated way across related proteins. AF2 reads these covariation patterns to infer which parts of the chain are in contact. Because the signal comes from the alignment itself, accuracy scales with the depth and diversity of the MSA, and proteins with few detectable homologs are harder to fold.

Internally, AlphaFold2 maintains two representations: an MSA representation and a pairwise representation over residue pairs. The Evoformer network repeatedly exchanges information between the two, using attention together with triangle-based updates on the pairwise representation that enforce geometric consistency among the inferred residue-residue distances. A structure module then turns these representations into an explicit 3D model, placing each residue as a rigid backbone frame with its own position and orientation. This whole process is recycled through the network several times, each pass refining the previous prediction. Along with the coordinates, AlphaFold2 emits two calibrated confidence measures: the per-residue predicted local distance difference test (pLDDT), which scores the model's confidence in each residue's local structure, and the predicted aligned error (PAE), which estimates the expected error in one residue's position when the structure is aligned on another.

This toolkit runs the original AlphaFold2 model through the [ColabDesign](https://github.com/sokrypton/ColabDesign) JAX implementation rather than the full DeepMind or ColabFold pipeline. There is no template-search stage, and multiple-sequence alignments are optional: they can be generated by a ColabFold search, supplied precomputed, or skipped to run in single-sequence mode. Beyond folding, the same model exposes a per-residue gradient, which gradient-based binder-design methods use to optimize a binder sequence against a frozen target.

## Tools

### AlphaFold2 Structure Prediction (`alphafold2-prediction`)

Predicts the 3D structure of one or more protein chains. Each input complex (a single chain, or several chains folded together) is run through the ColabDesign AlphaFold2 model, returning a predicted `Structure` per complex with confidence metrics: per-residue pLDDT, pTM, interface pTM for multi-chain complexes, and predicted aligned error.

#### Applications

This tool folds a protein sequence into a 3D model for structural analysis, docking, or as input to downstream structure tools. Running it on a multi-chain complex additionally estimates how confidently the chains are placed relative to each other through the interface pTM and PAE, which is informative for assessing predicted protein-protein interfaces.

#### Usage Tips

- **`use_msa` defaults to `True`.** An MSA is then generated by a ColabFold search for each protein chain; set it `False` for single-sequence prediction (faster, usually lower accuracy), or attach precomputed MSAs to the input to skip the search.
- **`model_num` and `num_ensemble_models` are mutually exclusive.** `model_num` (default `1`) selects one of AlphaFold2's five trained parameter sets; `num_ensemble_models` runs several and averages them for higher accuracy at higher cost. Setting both raises an error.
- **Confidence is reported as pLDDT, pTM, ipTM, and PAE.** Average pLDDT (0 to 1) is the primary per-structure quality metric; ipTM is populated only for multi-chain complexes. Set `include_pae_matrix` to attach the full per-residue PAE matrix.
- **Protein sequences only.** DNA, RNA, and ligands are not supported; `X` is allowed for unknown residues.

### AlphaFold2 Hallucination Gradient (`alphafold2-hallucination-gradient`)

Differentiates AlphaFold2's own confidence in a sequence that has no reference: ColabDesign's hallucination protocol folds the sequence alone and reports each requested quantity with its own raw gradient with respect to the sequence logits.

#### Applications

De novo design driven only by what AlphaFold2 believes about a sequence — maximizing confidence, encouraging compactness through contacts, or shaping secondary structure — with no target and no backbone to match.

#### Usage Tips

- **Select quantities with `gradient_terms`.** The protocol offers `plddt`, `pae`, `con`, `exp_res`, `helix`, `rg`, `NC` and `beta_strand`; each returns one `TermGradient` carrying its own value and its own gradient.
- **Terms are raw quantities, not objectives.** `plddt` is the confidence itself, not a loss, and no weight or direction is folded into its gradient. Combine them downstream with goals and weights.
- **`helix` and `beta_strand` have no built-in direction.** Lower means more helical contacts or more strand-like i,i+3 spacing, but whether that is wanted depends on the design, so composing them requires an explicit goal.
- **`positions` restricts a term to part of the designed chain.** `plddt`, `pae` and `beta_strand` (and `i_con` on the binder tool) take optional 1-indexed `positions`, e.g. the CDRs; without it a term covers its usual region. `beta_strand` also takes `form="out_of_range"`, which scores `-log(1 - P)` as Germinal does.
- **`rg` and `NC` shape the designed chain.** `rg` is the radius of gyration beyond `2.38 * N**0.365` and `NC` the terminal CA distance beyond 7 Å, as in BindCraft and Germinal; both are offered by all three tools.
- **One sequence per call; this tool is not an optimization loop.** Drive it from an optimizer, or call it repeatedly.

### AlphaFold2 FixBB Gradient (`alphafold2-fixbb-gradient`)

Differentiates how well a sequence reproduces a backbone it is supposed to fold into. ColabDesign's fixed-backbone protocol compares the prediction against a reference chain and adds the structural quantities that comparison makes available.

#### Applications

Sequence redesign for a known fold: driving a sequence toward a target backbone by `rmsd`, `dgram_cce` or `fape`, or scoring how well candidate sequences recover an existing structure.

#### Usage Tips

- **The logits must cover exactly the reference chain.** The designed length comes from the reference, so a matrix of a different length is rejected rather than padded; supply one row per residue of `reference_chain`.
- **`rmsd`, `dgram_cce` and `fape` exist only here.** They measure agreement with the reference, so they are meaningless without one and are absent from the other two tools.
- **`reference_chain` defaults to `"A"`.** Name the chain whose backbone the sequence should reproduce.

### AlphaFold2 Binder Gradient (`alphafold2-binder-gradient`)

Differentiates a de novo binder against a fixed target structure, using ColabDesign's binder protocol. The binder has no template of its own, which is what keeps the interface and confidence quantities informative.

#### Applications

Gradient-based binder design against a chosen epitope, optimizing interface contacts (`i_con`) and interface error (`i_pae`) alongside overall confidence.

#### Usage Tips

- **`i_con`, `i_pae`, `i_ptm` and `fw_i_con` exist only here.** They describe the binder-target interface, so they require the two-chain setup this protocol builds.
- **`fw_i_con` measures framework contact.** It is the `i_con` objective restricted to the 1-indexed binder `framework_positions` it is given, so higher means the framework sits farther from the target. Germinal's framework penalty is `i_con**2 / max(fw_i_con - offset, 1e-8)`, composed downstream from the two terms.
- **`target_hotspot` focuses the interface.** Supply ColabDesign-style residue selections on the target to bias the binder toward a specific epitope.
- **The target's template is masked by default.** `rm_target_seq` and `rm_template_ic` default to `True` so the target's own sequence and inter-chain contacts do not leak into the prediction; `use_multimer` defaults to `True`.
- **The binder length is the number of rows in the logits.** There is no binder template, so nothing else defines it.

## Migrating from `alphafold2-gradient`

The previous `alphafold2-gradient` tool is replaced by the three tools above. It returned one gradient of one weighted objective; these return one raw gradient per quantity, which the caller composes.

- **`loss_weights={"plddt": w, ...}` becomes `gradient_terms=["plddt", ...]`.** The weights move out of the tool: each requested quantity comes back with its own value and its own unweighted gradient, and weighting happens when the terms are composed.
- **Pick the tool that matches the design.** De novo with no reference → `alphafold2-hallucination-gradient`. Sequence against a known backbone → `alphafold2-fixbb-gradient`. Binder against a target → `alphafold2-binder-gradient`. Splitting them is what makes each tool's term catalog honest: the old tool accepted terms its protocol never computed and returned gradients of zero for them.
- **`binder_chain` has no successor.** It selected an existing chain of the target template to redesign, which made the binder supervised and silently zeroed the confidence quantities. No tool here reproduces template-based binder redesign.
- **`helix` now means ColabDesign's native helix loss** — a binary contact loss over i,i+3 pairs across the whole designed region — rather than the binder-only variant the previous tool registered. Its magnitude, normalization and sign convention all differ.
- **`rg`, `i_ptm`, `NC` and `beta_strand` are terms again**, and the Germinal framework-contact penalty is composed from `fw_i_con` and `i_con`. Germinal's CDR-restricted terms map to `positions`, and its strand loss to `beta_strand(form="out_of_range")`.
- **`backend="germinal"`, `starting_binder_seq`, `excluded_amino_acids` and `bias_redesign` are not carried over.**

- **Requires a GPU.** Every tool here runs AlphaFold2 through a JAX backend and need an NVIDIA GPU; CPU execution is not practical.
